## Featured Project

### FraudShield AI — Real-Time Fraud Detection & Decisioning Platform

FraudShield AI is an end-to-end fraud detection platform built to demonstrate how machine learning can move from offline model development into real-time scoring, automated decisioning, explainability, and investigation workflows.

**Key engineering components:**

- LightGBM fraud classifier using 38 engineered behavioral features
- Kafka-based real-time transaction pipeline
- Offline-to-online feature-state workflow
- Automated allow / alert / block decisioning
- SHAP-based prediction explainability
- Seven simulated fraud scenarios
- Fraud investigation and customer intelligence workflows
- Multi-page Streamlit operations console
- Automated tests and controlled streaming validation

**Model evaluation on synthetic test data:**

- Test PR-AUC: **~0.9665**
- Validation PR-AUC: **~0.8303**

> FraudShield AI uses synthetic transaction and fraud data. Reported model metrics therefore demonstrate the behavior of the simulated system and should not be interpreted as production financial-system performance.
